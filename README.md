### What I'm building

**[AI-ria](https://github.com/maribostashvili-93/ai-ria)** — runtime intelligence for AI coding agents
Every agent starts from zero: it re-reads the repo, re-derives the architecture, and forgets every decision when the session ends. AI-ria is the layer underneath them. It compresses a 2.6M-token repository into a ~12k-token knowledge pack, keeps layered memory across sessions, and hands one agent's state to the next — with provider packs sized for Claude, Cursor and Codex. 136 tests, MIT.

**[Beacon SEO](https://github.com/maribostashvili-93/Beacon-seo)** — *don't just tell me what's wrong, fix it*
Point it at a URL. It runs 35 technical and 8 keyword checks, cites the source line number for every finding, explains it in plain language, then generates the fix in the idiom of your actual framework. Next.js 15 dashboard, a `beacon` CLI with a CI gate, an MCP server, and Search Console / GA4 / Yandex integrations.
